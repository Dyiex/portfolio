# Portfolio: Diether Angelo C. Tindog

portfolio/
├── index.html          Page structure (Bootstrap 5.3 grid + components)
├── css/style.css       Colors, fonts and custom styles
├── js/main.js          Small scripts (footer year, mobile menu)
└── assets/
    ├── img/            Put photos and project screenshots here
    └── docs/           Optional: store documents here

Open index.html in a browser. Bootstrap loads from a CDN, so you need internet.
Change colors in the :root block at the top of css/style.css.

Photos: replace assets/img/profile.svg with your own picture (for example profile.jpg),
then change the src in the .hero-photo <img> tag in index.html.
Project covers are in assets/img/ and can be swapped for real screenshots the same way.
